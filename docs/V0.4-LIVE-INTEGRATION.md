# V0.4 Live Flight Intelligence

## Provider strategy

JASS uses a common normalized offer format.

```text
Provider API
   ↓
Provider Adapter
   ↓
Normalized Offer
   ↓
True Cost
   ↓
Connection Analyzer
   ↓
JASS Value Engine
   ↓
Explainable Recommendation
```

## Security

Do not put provider API keys in React/Vite environment variables that are shipped to the desktop renderer.

Use a server-side service or controlled backend proxy.

## Current status

The provider adapters are intentionally safe placeholders. They validate configuration and expose the correct boundary without inventing endpoint details or claiming live access.

Once an authorized provider account is available, its current API contract can be mapped into `normalizeOffer()`.
