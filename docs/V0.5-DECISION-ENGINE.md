# V0.5 — True Travel Decision Engine

The purpose of V0.5 is to turn a list of flight offers into a decision.

## Pipeline

```text
Flight Offers
   ↓
Normalized Offer
   ↓
True Cost
   ↓
Connection Risk
   ↓
Fare Flexibility
   ↓
JASS Value Score
   ↓
Decision Score
   ↓
Explainable Recommendation
```

## Decision dimensions

- advertised fare
- estimated true trip cost
- duration
- stops
- baggage
- emissions
- connection risk
- refundability
- changeability
- price position within the current result set

## Safety of interpretation

JASS should clearly distinguish:
- live provider data
- cached data
- demo data
- estimates

No recommendation should imply guaranteed future pricing or guaranteed connection success.
