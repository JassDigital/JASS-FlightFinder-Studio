# Provider activation checklist

Before enabling a live provider:

1. Obtain an authorized developer account.
2. Confirm current API product/contract and allowed use.
3. Store secrets only on the server.
4. Implement provider-specific authentication.
5. Map provider responses into `normalizeOffer()`.
6. Add retries, rate limits and error handling.
7. Add attribution/deep-link requirements where applicable.
8. Test price freshness and offer expiry.
9. Never present stale demo prices as live prices.
10. Keep the demo provider available for offline development.
