# V0.3 Search Intelligence

## Search modes

- Round Trip
- One Way
- Multi-City

## Airport intelligence

Search by:
- IATA code
- City
- Airport name
- Country
- Alias

Nearby-airport relationships are represented in the airport data and can be expanded later with a full airport database.

## Filters

- Maximum stops
- Minimum baggage
- Maximum journey duration
- Airline

## Flexible dates

The UI provides a seven-day exploration window centered on the selected date. V0.3 uses demo pricing; live prices must come from an authorized provider.

## Comparison

Up to three itineraries can be selected for comparison. V0.4 can turn this into a full comparison drawer with true-cost, connection and fare-rule analysis.
